\section{Introduction}
In this project we set out to analyse weather data from Sveriges meteorologiska och hydrologiska institut (SMHI) OpenData initiative. \\

To do this, we have first cleaned the data downloaded from the project template repository, making sure that there are no entries with invalid format, ordering the data chronologically and checking the data for unexpected behaviour, details of which are covered in the following data cleaning section. With cleaned \verb|.cvs| files, the data was converted to a \verb|TTree| that was then used in ROOT as a tree. The tree was used for analysis in task 3.1, 3.2 and a third extra task. In task 3.1 we set out to find the mean temperature for a selected calendar day over the years. In task 3.2 we found the mean temperature for each calendar day over the years. In the extra task, our goal was to investigate the number of days in a given year with mean temperature below $0\degree\text{C}$ over the time that the records were kept, in order to investigate if it agrees with our intuition about climate change. \\

The project was realised in GitHub, where we have created a repository with all team members as collaborators. In this way all team members were able to push their changes into the main repository without relying on the release manager to accept them. To make sure this does not cause any unexpected behaviour each team member worked in their development branch and pushed to the main only after verifying that the changes are working. The repository can be found here \url{https://github.com/0scarlight/MNXB11-team_3-final_Project/tree/main}.
