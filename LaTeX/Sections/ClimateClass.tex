The \textit{ClimateData} class is a custom class derived from \textit{TObject} and was created to be able to store and access the processed data in a tree. The class consists of member function that store each individual unit of time that occurs in the raw data file, the measurement, and the station name. The class has getter for every member variable and has four other getter to get formatted timestamps and dates. These special getters each time unit being a member variable and the station name are menat to allow for greater sorting and comparing of the data set for the data analysis.
